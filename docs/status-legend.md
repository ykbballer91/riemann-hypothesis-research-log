# Status legend

**STATUS: RIEMANN HYPOTHESIS OPEN**

| Label | Meaning in this repository |
|---|---|
| **PROVED** | A specified auxiliary claim has a written argument under its stated hypotheses. Read the proof and audit scope. This never labels RH itself. |
| **KNOWN** | A statement is taken from identified prior literature, with its hypotheses retained. |
| **CONDITIONAL** | An implication is established only assuming one or more stated, unproved inputs. |
| **NUMERICAL** | Finite computational observations or diagnostics; no untested asymptotic claim follows. |
| **FALSE** | A particular claim is contradicted by a proved example or calculation in its stated setting. |
| **REJECTED** | A proposed route fails its audit or provides no independent bridge. Rejection need not mean every ingredient is false. |
| **OPEN** | A necessary estimate, construction, comparison, or proof is absent. |
| **HEURISTIC** | An intuition used to generate a question, without being a proof premise. |
| **NOT STARTED** | The stated next task has not been performed in this snapshot. |

`PASS` in an audit or JSON record is a check result, not one of the mathematical labels above. It may concern a finite experiment, source preservation, publication hygiene, or a precisely scoped argument.

Historical labels stay attached to their original objects. Track-specific success levels are not combined into an overall score. There is no percentage-complete measure for RH in this log.
