## 技術的な内容

### CORE-S：厳密な偶奇順序から単純性へ

正準な有限Weil行列を $Q_{a,N}$、その偶・奇部分を $Q^+$、$Q^-$ とし、$a>0$、整数 $N\ge1$ とします。$e_+$、$e_-$ は各部分の最低固有値です。次が成立します。

$$e_+(a,N)<e_-(a,N)\quad\Longrightarrow\quad\dim\ker(Q^+-e_+I)=1.$$

全有限空間の最低値が単純で、その状態が偶であることを $\mathrm{ES}(a,N)$ と書けば、

$$\mathrm{ES}(a,N)\iff e_-(a,N)>e_+(a,N).$$

従来の独立条件 $\Delta_+(a,N)>0$ は、この厳密な順序から各有限点で従います。$N=0$ では奇部分が空になるため、ここでは扱いません。

### 使った構造と短い証明

CCMの既知の行列構造を使います。正準基底 $V_n$（$-N\le n\le N$）で $DV_n=nV_n$、反射を $J$、$\eta=\sum_nV_n$ とすると、奇ベクトル $\beta$ により

$$[D,Q]=|\beta\rangle\langle\eta|-|\eta\rangle\langle\beta|.$$

$$JQ=QJ,\qquad JD=-DJ,\qquad J\eta=\eta,\qquad J\beta=-\beta.$$

$$\ker D=\mathbb C V_0,\qquad\langle\eta,V_0\rangle=1.$$

偶最低固有空間を $U$ とし、$\xi\in U$ が $\eta$ に直交するとします。$\beta$ は奇なので $\xi$ に直交し、交換関係から $QD\xi=e_+D\xi$ となります。$D\xi$ は奇ですが、$e_+<e_-$ なら奇側にこの固有値はありません。したがって $D\xi=0$。上の核と内積の条件から $\xi=0$ です。つまり一つの線形汎関数 $\langle\eta,\cdot\rangle$ が $U$ 上で単射になり、$U$ は一次元です。

反対に全最低状態が単純かつ偶なら、奇側に同じ最低値は存在できません。これでESとの同値が得られます。RH・捕捉・未知の固有値差の下界を仮定した証明ではありません。

### 残る共同条件

$R_a$ を支持制限、$P_N$ を正準な有限フーリエ射影、$G_{+,j}$ を偶最低固有空間への直交射影とし、記録の規約で $\widehat k=\Xi/4$ とします。

$$C_j=\|(I-G_{+,j})P_{N_j}R_{a_j}k\|_2.$$

必要な未証明命題は、次を満たす**一つの同じ列の存在**です。

$$a_j\to\infty,\qquad\frac{a_j}{N_j+1}\to0,$$

$$C_j\to0,\qquad e_-(a_j,N_j)>e_+(a_j,N_j)\ \text{eventually}.$$

この前件が成立すれば、CORE-SによるESと、採用済みのES＋強L²移送を組み合わせられます。

$$\begin{aligned}
\text{same-sequence capture}+\text{strict parity}
&\Longrightarrow\mathrm{ES}\\
&\Longrightarrow\text{adopted transfer}\\
&\Longrightarrow\mathrm{RH}.
\end{aligned}$$

別々の列の結果は接合できません。この分岐へ旧CMP-Rの $\lambda^r$ 速度を追加しません。旧CMP-RはESに依存しない別の十分条件として保持します。
