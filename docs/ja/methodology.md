# 方法と証拠

**STATUS: RIEMANN HYPOTHESIS OPEN**

@ykbballer91が編集する、AIを用いた研究ログです。提案した機構、正確な計算、文献比較、構成の試み、反例、停止理由を記録します。元の会話を知らなくても読めるよう公開文を編集しています。

## 人間の方向付けとAI支援

公開者は問いの設定、仮説、抽象化の変更、解釈、継続・停止の指示を担いました。AI/Codexは文献検索、記号的導出、数値診断、証明の試み、反例探索、別担当による内部検討、公開準備を支援しました。著者表示は@ykbballer91です。人間だけの導出、または自律AIによるRHの証明を主張するものではありません。

## このログでの「監査」

独立した内部監査とは、別のAI担当が指定された数学的議論や計算資料を検査したことです。反証を試みる内部検査として有用ですが、外部査読、特定の数学者の承認、全主張の機械的検証ではありません。各監査に対象と範囲を記しています。

検証スクリプトは、ハッシュ、有限恒等式、リンク、構文、指定された認証などを調べます。`PASS`はその検査だけに適用します。過去の検証記録は元の実行の証拠であり、公開時に全実験を再実行したという意味ではありません。

Leanファイルは記録された環境で一部の補題を形式化しています。そのビルド成功は、研究全体・数値コード・RHの認証ではありません。

## 主張の規律

- 定理には空間、領域、量化、規格化、前提を記す。
- 条件付き含意の未証明の前提は明示する。
- 人工模型の反例は指定した性質からの推論を反証する。実際のゼータへの反例とは、証明しない限り扱わない。
- 有限計算は診断または指定認証の一部であり、未検査の極限評価の根拠にしない。
- ある位相の結果を、証明なしに別の位相へ移さない。
- 固定有限次元の結果を、記号だけで次元に一様な結果へ変えない。

## 原文と編集方針

研究原文は保存します。公開用コピーには別のハッシュと[編集対応表](../../audit/rewrite_manifest.md)があります。編集では機械固有の参照を除き、内部略語と案内を改善しますが、主張を強めたり失敗を消したりしません。

今回、公開案内・編集ページを日英に分離しました。研究報告、実験、監査、状態ファイルは原文のままです。履歴はGit時刻と報告書の日付を区別し、並行研究を架空の順序へ並べ替えません。原17トラックと後続の巡回性・有限空間の更新は区別します。

既知結果には記録にある一次資料を付けます。特定箇所の確認を論文全体の再証明とはしません。外部論文は再配布せずリンクします。
