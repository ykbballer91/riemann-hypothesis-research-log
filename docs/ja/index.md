# この研究ログの読み方

**STATUS: RIEMANN HYPOTHESIS OPEN**

リーマン予想は、ゼータ関数の非自明な零点がすべて実部 $1/2$ を持つとする予想です。このログでは、それを強制できる算術情報を探した過程と、別の表現へ移っても同じ未解決条件が残った箇所を記録しています。

編集は **@ykbballer91**、研究・監査・公開作業にはAIを利用しています。研究日、公開更新日、初回公開日は区別します。最新の編集上の状態は[現在地](current-state.md)にまとめ、以前の記録にはその時点の日付を残しています。

**結果と限界を知るには：** [現在地](current-state.md)から[ロードマップ](roadmap.md)へ進んでください。[最新のCORE-S更新](updates/2026-10-07-core-s.md)は、単純性の独立条件を外した有限補題と、同じ列で残る捕捉・厳密な偶奇順序を説明しています。[2026-10-05の共同移送](updates/2026-10-05-joint-transfer.md)も履歴として保存しています。

**検証・再利用するには：** [出典](source-map.md)、[参考文献](references.md)、[再現手順](reproducibility.md)を使ってください。研究原文、範囲を限定した内部監査、数値出力、形式化した補題は、それぞれ異なる証拠です。

## 繰り返し現れた壁

ゼータ零点の情報を保持する自然な構造は複数あります。難しいのは、臨界線から外れる成長を排除する独立した算術評価です。正の計量、拡大作用の有界性、Möbius和の平方根評価、実零点近似の収束は、必要な条件を表していても、その証明にはなりません。

後半では有限Weil形式とプロレート近似を調べています。制限された試行空間での最小化は、有限系全体の最低状態の同定とは異なります。定性的な稠密性や、固定した有限フーリエ空間の正確な生成だけでは、パラメータを増やしたときの一様評価は得られません。

## 状態ラベルの読み方

`PROVED` は前提と範囲を明記した補助結果、`KNOWN` は文献の既知結果、`CONDITIONAL` は未証明の前提を残す含意、`NUMERICAL` は有限計算です。`FALSE` と `REJECTED` は成立しなかった主張や方針、`OPEN` は未解決義務を示します。[状態ラベルの説明](status-legend.md)も参照してください。

内部AI監査は外部の査読ではありません。スクリプトの成功は、検査していない漸近命題の証明ではありません。十分な解像条件を、最適な閾値とは主張しません。
