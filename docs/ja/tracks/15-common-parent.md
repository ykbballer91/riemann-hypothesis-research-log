# 15. 共通の変分原理はあるか

**STATUS: RIEMANN HYPOTHESIS OPEN**

記録日：2026-09-30。報告書に記録された日付。個別の開始・終了時刻は復元しない。

## 着想

実際のWeil最低状態とプロレート近似は算術核の近くに見える。一つの変分原理が両者の一致を強制するかを調べた。

## 調べたこと

引き戻し Q(Eh)、誘導計量 E*E、積分ゼロのh₀/h₄混合と通常の集中最適状態の違いを固定し、エネルギー超過・残差・固有値差を検査した。

## 残った結果

単純な最低状態と正の固有値差Δのもとでは、Rayleigh超過による角度評価を (R_B − e₀)/Δ で制御できる。広がる支持上でFourier変換へ移すには重み付きノルムの因子も必要。既知の大域算術radicalは無限次元であり、その恒等式は有限プロレート近似を正確な零ベクトルにはしない。

## 成立しなかったこと・未証明のこと

共通親の恒等式や十分な超過／gapの減衰は未取得。大きなradicalから零に近いエネルギーだけで一意のベクトルを選べない。上界の比が大きくても、実際の距離の下界ではない。高精度有限診断は区間認証や全カットオフの定理ではない。

## 次の問いへ進んだ理由

有限切断が縮退をどう分裂させ、速度や経路履歴が方向を選ぶかを調べた。
