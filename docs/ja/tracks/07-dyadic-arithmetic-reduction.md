# 07. 二進的な算術還元

**STATUS: RIEMANN HYPOTHESIS OPEN**

記録日：2026-09-30。報告書に記録された日付。個別の開始・終了時刻は復元しない。

## 着想

2倍拡大を繰り返した後、類の代表元を対数直線の片側へ押し込み、ノルムを定量的に小さくできるかを調べた。

## 調べたこと

全整数にわたる算術和のMöbius反転、滑らかな切断、モーメント補正を使った。流れを2の冪で標本化しても、算術入力を2の冪だけへ制限するわけではない。

## 残った結果

任意の許容入力について右側の裾を消す明示的代表元を作り、無条件の上界 2ⁿᐟ²(1 + n) を得た。Mertens評価 M(X) = O(X^θ) を仮定すれば同じ構成の率は 2⁽θ⁻¹ᐟ²⁾ⁿ に改善する。逆向きの含意も記録した端点の劣指数評価族はRH同値である。

## 成立しなかったこと・未証明のこと

独立した端点の相殺は得られず、無条件指数1/2の最適性も示していない。コンパクト支持で折り畳む議論は実際の算術部分空間に阻まれ、切断だけでは修復できない。

## 次の問いへ進んだ理由

Möbiusの符号相殺へ移り、素数複体、素数位相、重み付き半空間を順に検査した。

## この記録の範囲

明示的還元と無条件の率は保持。目標の端点は同値な言い換えであり、RHの証明への新しい評価ではない。
