# 04. 算術的偏極と交点ペアリング

**STATUS: RIEMANN HYPOTHESIS OPEN**

記録日：2026-09-29。報告書に記録された日付。個別の開始・終了時刻は復元しない。

## 着想

既存の算術的交点理論や高さの定理から、零点を担う商に必要な正のペアリングを得られるかを調べた。

## 調べたこと

Arakelovの高さ、明示公式を「交点」と読む表現、アデールFourier対合、積公式を比較し、対象空間と極項の除去を確認した。

## 残った結果

既知の正値性定理は、指定された幾何学的領域では有効である。算術曲面の高さ理論と Spec Z 上の次数0の商は異なる。また指定の周囲の位相では、稠密なradical上で消える非零の可閉な正形式は存在できない。

## 成立しなかったこと・未証明のこと

既知の高さ空間と全零点表現を同定する写像は得られなかった。自然なFourier-star案には、極を消した実際の試験関数でも負の方向がある。これは提案したペアリングの反証であり、RHやWeil判定の反証ではない。「交点」と呼ぶだけで交点幾何やHodge指数定理は得られない。

## 次の問いへ進んだ理由

並行する拡大作用の調査では、実際の素数軌道を直接調べ、その後、一つの素数の帰還評価へ目標を弱めた。

## この記録の範囲

既知の幾何学定理は保持。必要な算術的偏極は構成できなかった。
