# 05. 連続的拡大と素数の帰還写像

**STATUS: RIEMANN HYPOTHESIS OPEN**

記録日：2026-09-29。報告書に記録された日付。個別の開始・終了時刻は復元しない。

## 着想

長さ log p の素数周期軌道について、実際の算術的帰還写像が、零点の実部1/2を説明するかを調べた。

## 調べたこと

写像トーラス、ファイバーのモノドロミー、局所p進横断作用、滑らかなPoincaré帰還写像を分離した。局所軌道のモードと全体の零点表現も区別した。

## 残った結果

既知の軌道 C_p = ℝ₊×/p^ℤ の長さは log p である。選んだ持ち上げでは被覆変換と正時間の逆帰還の規約を区別する。指定の向きでp進法方向の付値的成長指数は +1 になり得るため、「横断方向に成長がない」という文字通りの主張は偽。ただしその指数をゼータ零点の指標とは同定しない。

## 成立しなかったこと・未証明のこと

局所Haarユニタリ性では、余分なモードを持つ局所模型から離散的なゼータ零点因子を復元できない。全算術商上で零点情報を保つ共通Hilbert計量は未取得。シンプレクティック性、不定ペアリング、時間反転は代用にならない。

## 次の問いへ進んだ理由

p = 2 の帰還作用素が両方向で劣指数成長する、というより弱い要求へ進んだ。
