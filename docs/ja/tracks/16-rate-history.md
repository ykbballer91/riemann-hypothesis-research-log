# 16. 速度・履歴と有限切断による縮退の分裂

**STATUS: RIEMANN HYPOTHESIS OPEN**

記録日：2026-09-30。報告書に記録された日付。個別の開始・終了時刻は復元しない。

## 着想

支持とFourier切断の増やし方が、大域radicalから算術核を選ぶかを調べた。

## 調べたこと

支持制限 R_a と周期Fourier射影 P_N を分離し、素数冪が追加される閾値と、診断経路 N ≍ a²、N ≍ a³ を比較した。

## 残った結果

二次元族 span{k,k″} の支持制限だけの最小化は、規格化後にkを選ぶ。明示的境界相殺が率を改善する。各固定微分族の射影エネルギーには、二つの診断経路で0へ向かう無条件上界がある。同じ有限端点の単純な最低状態射影は履歴に依存しない。素数冪イベントは行列の跳びではなく微分の角を生む。

## 成立しなかったこと・未証明のこと

エネルギー上界は先頭漸近や最低状態選択の定理ではない。二つの微分を越えると先頭の零空間は多次元になる。この段階では、極限選択の経路依存も経路独立も証明していなかった。

## 次の問いへ進んだ理由

高次Schur項とより強いFourier解像尺度を使い、各固定有限微分族の階層を解く調査へ進んだ。

## この記録の範囲

速度と有限端点の事実は保持。後続の制限族の結果を、遡って全体の最低状態の定理としない。
