# 03. 欠けているFrobeniusの機構

**STATUS: RIEMANN HYPOTHESIS OPEN**

記録日：2026-09-29。報告書に記録された日付。個別の開始・終了時刻は復元しない。

## 着想

有限体の証明を使い、算術的起源・トレース・双対性・純性がどこで使われるかを調べた。類比を名前だけで整数上へ移すのではなく、欠けている定理の同定が目的だった。

## 調べたこと

曲線とJacobianの偏極、コホモロジーの純性、Deningerの構想、ゼータ零点を表す既存のアデール商を比較した。

## 残った結果

有限体上のアーベル多様体では、Rosatiペアリングの正値性と関係 π†π = q が同じ表現に作用する。既知のアデール試験関数商は対象零点を重複度込みで表すが、その位相・トレースの定理と正のHilbert空間による実現を区別した。

## 成立しなかったこと・未証明のこと

形式的な双対性と正の整数点数だけでは純性は出ない。自然な周囲の正のHilbertノルムでは、零部分空間が完備化で稠密となり、意図した商が潰れる。算術情報を失わず商へ降りる正のペアリングは得られなかった。

## 次の問いへ進んだ理由

算術的偏極の監査と、連続的拡大・素数の帰還写像の調査へ分岐した。
